# VI Neon Countdown 2.0 🌴

一款粉紫霓虹风格的非官方 GTA VI macOS 倒计时工具，由 **黄铜花雨**制作与维护。

## 功能

- 支持小、中、大三种桌面小组件。
- 显示剩余天数及小时、分钟、秒。
- 可在“编辑小组件”中设置开始年、月、日，进度条随时间逐渐填满。
- 设定的发售日当天显示专属庆祝画面，App 内可提前预览。
- 当前倒计时目标：**2026 年 11 月 19 日**。日期为应用内设定，不会自动同步官方公告。

## 系统要求

- macOS 15.0 或更高版本。
- 安装包包含 Apple 芯片和 Intel 两种架构；Intel 真机运行尚未验证。

## 下载与安装

1. 下载附件 `VI-Neon-Countdown-v2.0-macOS-Universal.zip`，不要选择自动生成的 `Source code` 压缩包。
2. 解压后，将 `VI Neon Countdown.app` 拖入“应用程序”文件夹。
3. 打开 App 一次。
4. 在桌面右键 → **编辑小组件**，搜索 `VI Neon Countdown` 并添加。

右键已添加的小组件 → **编辑小组件**，即可独立设置开始日期。App 内的预览设置不会同步改变桌面小组件。

## 注意事项

- 本版本使用 ad hoc 签名，**未经 Apple 公证**，系统可能阻止首次打开。请确认下载来源可信，不要关闭系统安全保护。
- 小组件刷新由 macOS 管理，跨日更新与庆祝画面切换可能略有延迟。
- 若更新后仍显示旧版内容，可移除旧小组件并重新添加。
- 已通过 Release 构建和签名完整性检查，尚未在其他 Mac 上完成安装测试。
